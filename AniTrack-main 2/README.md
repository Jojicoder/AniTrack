# AniTrack
AniTrack is an Anime and Manga Recommendation and Tracking website. The purpose of this website is to help users manage and organize their anime and manga watching experience. AniTrack helps users avoid losing track of their watch progress and provides a centralized platform to manage and discover anime/manga efficiently.
Users can create an account, log in, and keep track of what they are watching, what they have completed, and what they plan to watch. The system also allows users to rate and review anime/manga and discover new recommendations. The system stores user data, anime/manga information, and user activity in a structured database. This project simulates a real-world web application with both frontend (HTML, CSS, JavaScript) and backend (PHP, MySQL). In the future, the system can be expanded with social features such as following other users and sharing reviews.
